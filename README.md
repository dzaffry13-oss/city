# CITY: сайт агентства недвижимости

- `index.html`: сайт (публикуется через GitHub Pages)
- `worker/`: Cloudflare Worker, который пересылает заявки из формы в Telegram

## Подключение заявок в Telegram

Токен бота нельзя хранить в коде сайта: его увидит любой посетитель. Поэтому форма отправляет заявку в Worker, а токен лежит в секретах Cloudflare.

### 1. Узнайте chat id
1. Откройте своего бота в Telegram и нажмите Start (бот не может писать первым).
2. Напишите боту любое сообщение.
3. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`. В ответе найдите `"chat":{"id":...}`, это число и есть chat id.
   Если хотите получать заявки в группу, добавьте бота в группу, напишите там сообщение и возьмите id из того же ответа (он начинается с минуса).

### 2. Создайте Worker (через браузер, без установки программ)
1. Зарегистрируйтесь на cloudflare.com (бесплатный тариф подходит).
2. Workers & Pages → Create → Create Worker, назовите его `city-leads`, нажмите Deploy.
3. Нажмите Edit code, замените содержимое на код из `worker/worker.js`, нажмите Deploy.
4. Settings → Variables and Secrets:
   - Secret `BOT_TOKEN`: токен бота от @BotFather
   - Secret `CHAT_ID`: id из шага 1
   - Text `ALLOWED_ORIGINS`: `https://dzaffry13-oss.github.io` (при своём домене добавьте его через запятую)
5. Скопируйте адрес Worker, он выглядит как `https://city-leads.<имя>.workers.dev`.

### 3. Укажите адрес в сайте
В `index.html` найдите строку `const LEAD_URL="";` и впишите между кавычками адрес Worker. Сохраните файл, GitHub Pages обновит сайт через минуту.

### Проверка
Откройте сайт, отправьте тестовую заявку, она должна прийти в Telegram. Если токен бота когда-либо попадал в чат или переписку, перевыпустите его: @BotFather → /revoke.

## Номер телефона
Один номер для звонка, WhatsApp и Telegram задан в начале скрипта в `index.html` (`PHONE_DIGITS`, `PHONE_TEXT`).

## Панель управления объектами
Адрес: `…/admin.html` (на сайте ссылок на неё нет, поисковики её не индексируют). Через неё добавляют, меняют, скрывают и удаляют объекты, загружают фото (они сами уменьшаются, на них ставится логотип). Панель правит `listings.json` и папку `assets` прямо в репозитории, сайт обновляется через 1–2 минуты.

Вход: ключ GitHub (fine-grained token) с правом Contents: Read and write только на репозиторий `city`. Ключ хранится в браузере и никуда не отправляется, кроме GitHub. Инструкция по созданию ключа показана на экране входа.

Поле `hidden: true` в объекте прячет его из каталога (панель ставит его кнопкой «Скрыть»).

## Как добавить объект вручную
Откройте `listings.json`, скопируйте последнюю запись в конец списка и поправьте поля. Укажите новый `id` (больше всех существующих): объекты с большим `id` показываются выше, то есть новые появляются сверху.
- `extra` — короткая подпись в карточке, например `"Этаж 1 из 4"`.
- `description` — подробное описание, показывается в окне «Подробнее».
- `floor` и `floors` — этаж и этажность, в окне показываются как «Этаж 1 из 4».
- `image` — путь к фото, например `"assets/ataeva-25-2.jpg"` (файл загрузите в папку `assets`).

## Фото с водяным знаком
Логотип накладывается на фото скриптом: `python tools/watermark.py исходное.jpg assets/имя-объекта.jpg` (нужен Pillow: `pip install pillow`). Имена файлов в `assets` лучше писать латиницей без пробелов. Исходное фото без знака в репозитории лучше не хранить, оно будет доступно всем.
