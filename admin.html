Вход в панель

Один раз подключите панель к сайту. Ключ хранится только в этом браузере.

  1. Откройте создание ключа на GitHub (войдите в свой аккаунт).
  2. Название: CITY admin. Срок действия: 1 год (максимум).
  3. Repository access: Only select repositories → выберите city.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Нажмите Generate token, скопируйте ключ (начинается с github_pat_) и вставьте ниже.

Никому не передавайте ключ. Если потеряли телефон или компьютер, удалите ключ на странице GitHub → Settings → Developer settings.
